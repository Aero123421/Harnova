# Page style

## Summary

Make usage, configuration, failures, and limitations easy to find.

## Short summary

Explain the package's observable capability and main limitation. Use the length needed to orient the reader; there is no fixed word ceiling.

## Controlled technical English

Use precise actors, verbs, conditions, and exceptions. Japanese and English are both supported authoring languages. Preserve `must`, `may`, and negative guarantees when they describe real behavior.

## Section separators

Choose headings and spacing that help navigation. Decorative separators are optional.

## Foldable content sections

Use folds for secondary detail when they improve readability, without hiding essential instructions.

## Emphasis discipline

Reserve emphasis for facts that change an action or expectation.
