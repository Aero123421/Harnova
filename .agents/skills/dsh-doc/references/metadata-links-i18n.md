# Metadata and links

## README metadata

Keep frontmatter consumed by repository tools, including an accurate `description` and `kind`. New human-only documents need only metadata their consumers require.

## The kind system

The [templates](../templates/) cover package-group, package-reference, package-library, package-bundle, persistence-change, persistence-release, persistence-format, and upgrade-guide. Classify packages by manifest and entry: plain module API is a library, Cordis service or apply export is a plugin, and `dsh.bundle.patch` declares a bundle layer.

## Description quality

Describe an observable capability or the information a reader can find.

## Repository links and path mentions

Use local Markdown links for current files and exact source references for historical evidence. Repair current inbound links when moving a page.

## Bilingual line alignment

No bilingual line alignment is required. Write documentation in the language needed by its readers.

## Bilingual consistency records

Documentation does not require translated siblings or hash sidecars. Product UI locale dictionaries remain separately enforced.
